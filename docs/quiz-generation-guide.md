# 모리의 책숲 문제 생성 가이드

> 문서 상태: 다음 퀴즈 개편을 위한 제품·콘텐츠 명세
> 적용 레벨: Lv1, Lv2
> 제외 레벨: Lv3
> 주의: 이 문서는 문제 생성 기준을 정의한다. 앱 코드 반영은 별도 작업으로 진행한다.

## 1. 목적

이 문서는 책 한 권을 분석한 뒤 아이가 태블릿에서 스스로 풀 수 있는 Lv1 문제와,
객관 문제·말하기·녹음을 결합한 Lv2 문제를 일관되게 만들기 위한 기준이다.

문제 수를 늘리는 것보다 다음 세 가지를 우선한다.

1. 책에서 직접 확인할 수 있는 내용과 추론·확장 활동을 구분한다.
2. 아이의 발달 수준에 맞는 문장 길이와 상호작용을 사용한다.
3. 객관 문제 점수와 말하기 활동 기록을 섞지 않는다.

## 2. 전체 학습 흐름

```text
책 선택
  ↓
8장면 줄거리 그림과 문장 살펴보기
  ↓
Lv1: 아이가 혼자 객관 퀴즈 풀기
  ↓
Lv1 결과
  ├─ [Lv2 도전하기] → Lv2 시작
  └─ [오늘은 여기까지] → 책장에 기록

Lv2 시작
  ↓
줄거리 다시 읽기 + 낭독 녹음
  ↓
객관 문제와 말하기·녹음 문제를 섞어서 진행
  ↓
Lv2 결과: 객관 점수 / 말하기 완료 기록을 따로 표시
```

### Lv1 완료 후 제안 화면

Lv1 마지막 문제 직후 자동으로 Lv2를 시작하지 않는다. 아이가 성공감을 확인한 뒤
직접 선택하게 한다.

- 제목 예시: `혼자 힘으로 Lv1을 끝냈어요!`
- 설명 예시: `이제 책 속 내용을 떠올려 말해 보는 Lv2에 도전할까요?`
- 주 버튼: `Lv2 도전하기`
- 보조 버튼: `오늘은 여기까지`

`Lv2 도전하기`를 누르면 Lv2의 첫 객관 문제로 바로 이동하지 않고 반드시
`줄거리 다시 읽기 + 녹음하기`부터 시작한다.

## 3. 공통 입력 자료

문제를 생성하기 전에 다음 자료가 준비되어야 한다.

### 필수 자료

- 책 ID, 제목, 출판사, 시리즈
- 대상 연령
- 책의 핵심 주제 1–3개
- 순서가 정해진 8개 줄거리 장면
- 장면마다 대응하는 한 문장 요약
- 장면별 근거 ID
- 원문 페이지 확인 상태

근거 ID는 책마다 고유한 접두사를 사용한다.

```yaml
bookId: money
anchors:
  M1: 아이의 방에 저금통 친구가 찾아온다.
  M2: 저금통 친구가 동전과 지폐를 보여 준다.
  M3: 물건을 사기 전에 가격과 가진 돈을 비교한다.
```

### 근거 상태

각 책과 문항에는 아래 상태 중 하나를 기록한다.

| 상태 | 의미 | 사용 범위 |
|---|---|---|
| `page-verified` | 실제 책 페이지와 대조함 | 정답·해설에 사용 가능 |
| `adapted-story` | 앱의 각색 줄거리만 확인함 | 프로토타입 문제에 사용 가능 |
| `needs-verification` | 출처가 불명확함 | 아이에게 공개하지 않음 |

`adapted-story` 상태의 정보를 원문에 나온 정확한 사실처럼 홍보하거나 표시하지 않는다.

## 4. 출처와 정답 작성 원칙

모든 문제에는 아래 정보가 있어야 한다.

- `sourceAnchors`: 근거가 되는 장면 ID
- `sourceEvidence`: 정답을 지지하는 근거 요약
- `sourceRelation`: `direct`, `inference`, `extension` 중 하나
- `sourceStatus`: 원문 확인 상태

### 관계 구분

| 관계 | 설명 | 객관 정답으로 사용 |
|---|---|---|
| `direct` | 장면이나 본문에서 직접 확인 가능 | 가능 |
| `inference` | 두 장면 이상의 관계를 이용한 합리적 추론 | Lv2에서 제한적으로 가능 |
| `extension` | 아이의 경험, 새로운 대상, 추가 조사로 확장 | 말하기 문제만 가능 |

### 금지 규칙

- 책에 없는 원인이나 결과를 정답처럼 만들지 않는다.
- 상식적으로 맞더라도 현재 근거에서 확인되지 않으면 객관 정답에 넣지 않는다.
- 그림만으로 확인할 수 없는 인물의 마음을 단정하지 않는다.
- 아이를 속이기 위한 말장난, 이중 부정, 지나치게 비슷한 오답을 사용하지 않는다.
- `모두 맞다`, `알 수 없다`를 습관적으로 정답으로 사용하지 않는다.
- 원문 문장을 길게 복제하지 않고 짧게 바꾸어 쓴다.

예를 들어 이야기에서 `토마토가 농장에서 자라 트럭을 타고 공장으로 간다`까지만
확인했다면, 토마토가 공장에서 케첩이 되었다고 정답을 만들면 안 된다.

### 보기 자연스러움 원칙

보기는 정답 하나와 아무 말이나 만든 오답 세 개의 조합이 아니다. 네 보기 모두
질문과 같은 범주에 속하고 문법적으로 자연스러워야 하며, 아이가 책의 내용을
떠올려야 정답을 구분할 수 있어야 한다.

#### 좋은 오답의 출처

오답은 가능한 한 다음 자료에서 가져온다.

- 같은 책의 다른 장면에 실제로 나온 대상·장소·행동
- 등장 대상의 역할이나 장소를 서로 바꾼 내용
- 실제 사건 두 개의 순서를 바꾼 내용
- 핵심 개념과 같은 범주에 있지만 이 장면에는 해당하지 않는 낱말
- 아이가 장면을 부분적으로 기억할 때 고를 수 있는 가까운 오개념

책에 전혀 나오지 않는 엉뚱한 사물이나 행동을 웃기기 위한 오답으로 넣지 않는다.
오답도 책의 세계 안에서 자연스럽게 읽혀야 한다.

#### 네 보기의 평행성

한 문항의 네 보기는 다음 조건을 모두 만족해야 한다.

- 모두 명사구이거나 모두 완전한 문장처럼 문법 형식이 같다.
- 문장 종결 표현을 `~했어요`, `~에서 와요`처럼 통일한다.
- 정답만 유난히 길거나 구체적이지 않다.
- 네 보기의 길이는 가능한 한 비슷하며 가장 긴 보기가 가장 짧은 보기의 두 배를 넘지 않는다.
- 정답만 질문의 핵심 낱말을 그대로 반복하지 않는다.
- 정답만 긍정문이고 오답은 모두 부정문인 구조를 만들지 않는다.
- `항상`, `절대로`, `무조건`, `~만` 같은 극단 표현으로 오답을 쉽게 드러내지 않는다.
- 네 보기 중 정답은 하나뿐이며 부분적으로 맞는 두 번째 답이 없어야 한다.

#### AI가 만든 티가 나는 보기

다음 패턴이 하나라도 있으면 보기를 다시 만든다.

- 음식 문제에 `동전`, 돈 문제에 `우주선`처럼 범주가 전혀 다른 단어가 들어간다.
- 정답은 자연스러운 문장인데 오답은 `숨길 수만 있어요`처럼 억지 표현이다.
- 세 오답이 모두 황당해서 책을 읽지 않아도 정답이 보인다.
- 정답만 다른 보기보다 두 배 이상 길고 설명이 자세하다.
- 오답을 만들기 위해 책에 없는 사건이나 원인을 불필요하게 꾸며 낸다.
- 같은 오답 낱말을 여러 문제에서 반복한다.
- 보기마다 높임말, 시제, 조사, 문장 종결이 다르다.
- 질문과 결합했을 때 문법적으로 성립하지 않는 보기가 있다.

#### 보기 생성 절차

1. 근거 장면에서 정답을 먼저 확정한다.
2. 책 전체에서 정답과 같은 범주의 대상·장소·행동을 찾는다.
3. 역할 바꾸기, 장면 바꾸기, 순서 바꾸기로 오답 후보를 5개 이상 만든다.
4. 사실일 가능성이 있거나 의미가 겹치는 후보를 제거한다.
5. 남은 후보 중 문법 형식과 길이가 가장 비슷한 3개를 선택한다.
6. 질문과 네 보기를 차례로 소리 내어 읽어 어색한 조사를 고친다.
7. 책을 읽지 않고 보기 모양만 보았을 때 정답이 드러나는지 확인한다.
8. 한 책 안에서 정답 위치가 특정 번호에 몰리지 않도록 순서를 배치한다.

#### 생성과 검수 분리

보기 초안을 만든 생성 단계와 자연스러움을 판정하는 검수 단계를 분리한다. 같은 생성
응답 안에서 `좋은 보기입니다`라고 자체 확인하는 것만으로 검수를 끝내지 않는다.

1. 1차 생성기는 근거·정답·오답 후보를 만든다.
2. 2차 검수기는 정답 번호를 숨긴 질문과 보기만 읽고 다음을 판정한다.
   - 한국어로 자연스럽게 읽히는가?
   - 문법이나 길이만으로 특정 보기가 정답처럼 보이는가?
   - 두 개 이상이 답으로 해석될 가능성이 있는가?
   - 책을 읽지 않아도 황당한 오답 세 개를 제거해 답을 맞힐 수 있는가?
3. 형식 검수 뒤 정답과 장면 근거를 공개해 정답의 유일성과 오답의 근거를 확인한다.
4. 하나라도 실패하면 질문은 유지하고 보기 네 개를 다시 만든다.
5. 세 번 다시 만들어도 통과하지 못하면 `guardian-review-required`로 표시하고 공개하지 않는다.

최종 공개 가능한 상태는 `optionReviewStatus: approved`뿐이다.

#### 보기 검수표

각 선택형·빈칸 문항에는 생성 결과와 함께 내부 검수용 `optionAudit`을 출력한다.
이 정보는 아이 화면에는 표시하지 않는다.

```yaml
optionAudit:
  sameCategory: true
  parallelGrammar: true
  similarLength: true
  exactlyOneAnswer: true
  answerPositionBalanced: true
  solvableByAppearanceOnly: false
  awkwardnessFlags: []
  distractors:
    - option: 달걀은 젖소 농장에서 와요.
      source: 책에 나온 음식과 장소의 역할 바꾸기
      plausibleBecause: 음식과 농장 정보를 부분적으로 기억하면 헷갈릴 수 있음
      falseBecause: 장면 O3은 달걀이 양계장에서 온다고 알려 줌
```

`sameCategory`, `parallelGrammar`, `similarLength`, `exactlyOneAnswer` 중 하나라도
`false`이거나 `awkwardnessFlags`가 비어 있지 않으면 그 문항의 보기를 다시 만든다.

```yaml
optionReviewStatus: approved
optionReviewPass: 2
optionRevisionCount: 1
```

## 5. Lv1 생성 규칙

### 목표

Lv1은 4–5세 아이가 보호자의 답변 도움 없이 화면과 읽어주기 기능을 이용해
스스로 완주하는 단계다. 말하기, 녹음, 자기평가 카드는 사용하지 않는다.

### 권장 구성

- 총 6문제
- 전부 객관 채점
- 모든 선택형 문항의 보기는 4개
- 순서 문제는 4장면
- 문제 한 문장에는 한 가지 행동만 요구
- 정답 근거는 모두 `direct`
- 빈칸 완성과 책 전체의 중심 생각 문제는 Lv2에서만 사용

### 권장 문제 순서

| 순서 | 유형 | 목적 |
|---:|---|---|
| 1 | 핵심 대상 선택 | 인물·사물·장소 찾기 |
| 2 | 장면 행동 선택 | 누가 무엇을 했는지 찾기 |
| 3 | 직접 정보 선택 | 음식이 온 장소·돈의 모양처럼 한 장면의 사실 찾기 |
| 4 | 구체물 짝 연결 | 음식과 장소·사물과 행동 연결 |
| 5 | 4장면 순서 | 시작·전개·변화·결과의 흐름 이해 |
| 6 | 마지막 결과 선택 | 이야기 끝에 실제로 일어난 일 확인 |

책의 구조에 따라 3번과 4번의 순서는 바꿀 수 있다. 같은 종류의 선택 문제를
세 번 이상 연속 배치하지 않는다. Lv1에서는 여러 장면을 종합해야 하는 중심 생각,
원인 추론, 공통점·차이점, 조사 계획을 묻지 않는다.

### Lv1 상호작용

- 보기 전체가 최소 44×44 CSS 픽셀의 누르기 영역이어야 한다.
- 문제와 보기는 읽어주기 버튼으로 들을 수 있어야 한다.
- 첫 오답에는 정답을 공개하지 않고 오답 보기 하나를 제거한 뒤 한 번 더 기회를 준다.
- 두 번째 오답에는 정답과 한 문장의 책 속 단서를 보여 준다.
- 세밀한 드래그가 필요한 활동보다 누르기와 간단한 선긋기를 우선한다.

### Lv1 이미지 정책

Lv1 퀴즈에는 문제 전용 이미지를 생성하지 않는다. 책을 시작하기 전에 보는 기존
8장면 줄거리 그림은 유지하지만, 퀴즈 문항과 보기에는 새로 생성한 이미지를 사용하지 않는다.

- `image-choice` 유형을 만들지 않는다.
- 문항 데이터에 `visual`, `visualAlt`, `imageOptions`, `imagePrompt`를 만들지 않는다.
- 생성 결과에 이미지 생성 프롬프트를 포함하지 않는다.
- 질문과 보기, 짝 연결 카드, 순서 카드는 짧은 텍스트로 구성한다.
- 아이가 글을 읽기 어려울 때는 새 그림 대신 문제·보기 읽어주기를 제공한다.
- 이모지는 정답 단서가 되거나 의미를 모호하게 만들 수 있으므로 기본적으로 사용하지 않는다.
- 기존 8장면 줄거리 그림을 퀴즈 정답의 유일한 근거로 요구하지 않는다.

### Lv1 문제 예시

```yaml
id: origin-lv1-03
level: lv1
kind: choice
type: 시작 찾기
question: 배추는 무엇에서 자라기 시작하나요?
options:
  - 밭에 심은 작은 씨앗
  - 양계장에서 얻은 달걀
  - 젖소 농장에서 얻은 우유
  - 농장에서 자란 토마토
answer: 0
sourceAnchors: [O2]
sourceEvidence: 배추는 밭의 작은 씨앗에서 자라기 시작한다.
sourceRelation: direct
sourceStatus: adapted-story
explanation: 배추는 밭의 흙에 심은 작은 씨앗에서 자라기 시작해요.
```

## 6. Lv2 시작 활동: 줄거리 읽고 녹음하기

Lv2는 줄거리 읽기와 낭독 녹음으로 시작한다. 이 녹음은 객관 점수에 포함하지 않는다.

### 진행

1. 8장면과 대응 문장을 함께 보여 준다.
2. 아이가 각 문장을 눌러 읽어주기를 들을 수 있게 한다.
3. 준비가 되면 `줄거리 녹음 시작`을 누른다.
4. 아이가 8문장을 소리 내어 읽는다.
5. 녹음을 다시 듣거나 한 번 다시 녹음할 수 있다.
6. `이 녹음으로 시작하기`를 누르면 Lv2 문제로 이동한다.

### 기록

- 활동 ID: `lv2-baseline-read-aloud`
- 완료 조건: 1초 이상의 녹음 파일 저장
- 객관 점수: 없음
- 용도: 같은 책을 다시 읽었을 때의 낭독 변화 비교
- 저장: 기본적으로 현재 기기의 IndexedDB
- 삭제: 보호자 또는 아이가 명시적으로 삭제 가능

음성 인식 결과만으로 발음이나 문해력을 자동 판정하지 않는다. 향후 분석 기능을
도입하더라도 보호자 동의, 오류 가능성 안내, 원본 음성 삭제 기능이 필요하다.

## 7. Lv2 생성 규칙

### 목표

Lv2는 6–7세 아이가 책 속 정보를 떠올리고, 관계와 순서를 설명하며, 자기 말로
내용을 재구성하는 단계다.

### 기본 구성

- 시작 활동 1개: 줄거리 낭독 녹음
- 본 문제 총 9개
- 객관 문제 5개
- 말하기·녹음 문제 4개
- 객관 문제와 말하기 문제를 섞어서 배치
- 객관 점수와 말하기 완료 수를 별도로 표시

### 권장 진행 순서

| 순서 | 채점 | 유형 | 문제 틀 |
|---:|---|---|---|
| 시작 | 녹음 | 줄거리 낭독 | 8장면 줄거리 읽고 녹음하기 |
| 1 | 객관 | 빈칸 완성 | 책에서 배운 내용을 떠올려 문장 채우기 |
| 2 | 객관 | 과정 연결 | 장면과 과정 낱말 이어 보기 |
| 3 | 말하기 | 핵심 정보 회상 | 두 가지 이상 말하거나 한 음식의 여행 설명하기 |
| 4 | 객관 | 직접 확인 | 이야기에서 직접 확인할 수 있는 내용 고르기 |
| 5 | 객관 | 4장면 순서 | 흐름에 맞게 장면 차례대로 놓기 |
| 6 | 말하기 | 이야기 구조 | 처음·가운데·끝으로 다시 말하기 |
| 7 | 객관 | 중심 생각 | 책 전체가 가장 잘 알려 주는 내용 고르기 |
| 8 | 말하기 | 비교 | 공통점과 차이점 말하기 |
| 9 | 말하기 | 탐구 확장 | 새 질문과 조사 순서 만들기 |

### 레벨 간 중복 방지

같은 책을 다시 다루므로 Lv1과 Lv2가 동일한 장면을 사용하는 것은 허용한다. 그러나
질문, 정답, 사고 활동이 같은 문제를 반복해서는 안 된다.

| 구분 | Lv1 | Lv2 |
|---|---|---|
| 내용 찾기 | 한 장면에서 보이는 사실 찾기 | 여러 장면의 정보를 결합하거나 출처 경계 판단 |
| 짝 연결 | 음식↔장소처럼 구체물 연결 | 장면↔기르기·옮기기·가공하기 같은 개념 연결 |
| 순서 | 서로 이어지는 구체적인 4장면 배열 | 떨어진 핵심 4장면으로 전체 흐름 재구성 |
| 중심 생각 | 사용하지 않음 | 책 전체를 아우르는 문장 판단 |
| 말하기 | 사용하지 않음 | 정보 2개 이상 회상·구조화·비교·확장 |

다음 조건에 해당하면 중복 문제로 판정하고 Lv2 문제를 다시 만든다.

- Lv1과 Lv2의 질문 문장이 같거나 일부 낱말만 바뀌었다.
- `같은 근거 장면 + 같은 정답 + 같은 사고 활동`을 사용한다.
- Lv2의 정답 문구가 Lv1의 정답과 실질적으로 같다.
- 아이가 Lv1에서 본 정답 하나만 기억해도 Lv2 문제를 풀 수 있다.
- 선택지 순서만 바꾸거나 보기 수만 늘렸다.

Lv2 객관 문제는 직접 확인 문제를 제외하고 가급적 두 개 이상의 장면 근거를 사용한다.
말하기 문제는 Lv1에서 다룬 사실을 다시 사용할 수 있지만 반드시 다음 중 하나 이상을
추가로 요구해야 한다.

- 관련 정보 두 가지 이상
- 사건의 순서
- 처음·가운데·끝 구조
- 공통점과 차이점
- 책 속 근거가 포함된 설명
- 새로운 질문과 조사 계획

### 중복 검사표

Lv2 문제를 만든 뒤 가장 비슷한 Lv1 문제와 비교한 표를 반드시 출력한다.

```yaml
overlapAudit:
  - lv2QuestionId: origin-lv2-02
    closestLv1QuestionId: origin-lv1-04
    sharedAnchors: [O2]
    lv1Action: 음식과 출발 장소를 직접 연결
    lv2Action: 장면을 생산 과정 개념과 연결
    sameAnswer: false
    duplicateRisk: low
    decision: keep
```

`duplicateRisk`는 `low`, `medium`, `high` 중 하나로 기록한다. `high` 문항은 출력 전에
반드시 다시 만들고, `medium` 문항은 두 레벨의 사고 활동 차이를 설명할 수 있을 때만
사용한다.

## 8. Lv2 객관 문제 템플릿

### 8.1 책에서 배운 내용을 떠올려 문장을 채워 보세요

```yaml
kind: completion
scoreMode: objective
question: 책에서 배운 내용을 떠올려 문장을 채워 보세요.
sentence: 일을 하고 그 대가로 돈을 얻는 것을 ‘돈을 ____’고 해요.
options: [번다, 쓴다, 모은다, 빌린다]
answer: 0
```

작성 기준:

- 빈칸은 한 곳만 사용한다.
- 핵심 개념어 또는 핵심 서술어를 묻는다.
- 보기 없이도 문장 뜻을 추측할 수 있게 작성한다.
- 오답은 문법적으로는 들어갈 수 있지만 책의 내용과는 달라야 한다.

### 8.2 장면과 과정 낱말을 알맞게 이어 보세요

```yaml
kind: match
scoreMode: objective
leftItems:
  - 밭에서 씨앗이 자라요
  - 트럭을 타고 가요
  - 공장에서 치즈를 만들어요
rightItems:
  - 기르기
  - 옮기기
  - 가공하기
```

작성 기준:

- 왼쪽과 오른쪽은 각각 3개를 권장한다.
- 하나의 오른쪽 답을 두 항목에 중복 연결하지 않는다.
- 장면 묘사는 구체적으로, 과정 낱말은 짧게 쓴다.

### 8.3 이야기에서 직접 확인할 수 있는 내용은 무엇인가요?

책에 나온 사실과 책에 나오지 않은 설명을 구별하는 문제다.

돈 책 예시:

> 이야기에서 직접 확인할 수 있는 내용은 무엇인가요?

- 마음대로 그린 돈은 가게에서 쓸 수 없었어요. `정답`
- 마음대로 그린 돈을 저금통에 모았어요.
- 마음대로 그린 돈으로 물건을 샀어요.
- 마음대로 그린 돈을 일의 대가로 받았어요.

음식 책 대체 예시:

> 공장에서는 우유로 무엇을 만들었나요?

- 치즈를 만들었어요. `정답`
- 버터를 만들었어요.
- 요구르트를 만들었어요.
- 아이스크림을 만들었어요.

버터·요구르트·아이스크림은 우유로 만들 수 있어 현실적으로 그럴듯하지만, 현재
이야기 장면에서 직접 확인되는 답은 치즈뿐이다. 오답의 이유를 책이 설명한 것처럼
새로 만들지는 않는다.

### 8.4 흐름에 맞게 장면을 차례대로 놓아 보세요

- 보기 4개를 사용한다.
- 시작, 핵심 변화 2개, 결과가 드러나게 한다.
- 정답 순서는 실제 장면 근거와 일치해야 한다.
- 카드 문장은 각각 하나의 사건만 담는다.

돈 책 예시:

```text
저금통 친구가 찾아옴
→ 동전과 지폐를 보여 줌
→ 일의 대가로 돈을 벌 수 있음을 앎
→ 쓰지 않은 동전을 모음
```

음식 책 예시:

```text
마트 음식의 고향을 궁금해함
→ 재료가 농장과 밭에서 출발함
→ 재료가 옮겨지고 만들어짐
→ 여러 재료가 모여 샌드위치가 됨
```

### 8.5 이 책 전체가 가장 잘 알려 주는 내용은 무엇인가요?

- 정답은 여러 장면을 함께 설명해야 한다.
- 한 장면에만 맞는 세부 내용은 오답으로 사용할 수 있다.
- 너무 넓어서 어느 책에도 맞는 문장은 피한다.

돈 책 정답 예시:

> 돈은 벌고 쓰고 모으면서 계획할 수 있어요.

음식 책 정답 예시:

> 음식은 여러 장소와 사람의 과정을 거쳐 우리에게 와요.

## 9. Lv2 말하기·녹음 문제 템플릿

모든 말하기 문제는 실제 녹음으로 완료한다. `잘 말했어요`, `힌트를 보고 말했어요`처럼
아이에게 수행 여부를 대신 선택하게 하지 않는다.

### 공통 화면 구성

1. 말하기 질문
2. 선택해서 볼 수 있는 힌트
3. `녹음 시작` 버튼
4. 녹음 중 시간과 `멈추기` 버튼
5. 다시 듣기
6. `다시 녹음`과 `이대로 제출` 버튼

권장 녹음 시간:

- 최소 3초
- 권장 10–40초
- 최대 60초

### 9.1 핵심 정보 두 가지 이상 말하기

돈 책:

> 책에서 돈과 관련해 배운 일을 두 가지 이상 말해 보세요.

힌트:

- 돈을 어떻게 얻었나요?
- 돈으로 무엇을 할 수 있나요?
- 쓰지 않은 돈은 어떻게 했나요?

음식 책:

> 음식 하나를 골라 출발한 곳과 지나온 길을 순서대로 말해 보세요.

힌트:

- 어디에서 시작했나요?
- 무엇을 타고 이동했나요?
- 어디에 도착하거나 무엇으로 바뀌었나요?

### 9.2 처음·가운데·끝으로 이야기 다시 말하기

돈 책:

> 처음·가운데·끝을 생각하며 이야기를 짧게 다시 말해 보세요.

음식 책:

> 마트에서 만난 우주 친구에게 음식이 어디에서 오는지 두 가지 예로 설명해 주세요.

말하기 도움은 완성 답안을 그대로 보여 주지 않고 구조만 제공한다.

```text
처음에는 ______.
그다음에는 ______.
마지막에는 ______.
```

### 9.3 공통점과 차이점 비교하기

음식 책:

> 배추와 우유의 여행을 비교해 공통점 한 가지와 차이점 한 가지를 말해 보세요.

돈 책에 같은 기능을 적용할 때:

> 돈을 쓰는 것과 모으는 것을 비교해 공통점 한 가지와 차이점 한 가지를 말해 보세요.

비교 대상은 책에 정보가 충분히 나온 두 가지로 제한한다. 한쪽에만 정보가 있으면
비교 문제를 만들지 않는다.

### 9.4 새 질문과 조사 순서 만들기

음식 책:

> 책에 나오지 않은 음식 하나를 골라 ‘어디서 왔을까?’를 알아볼 질문과 조사 순서를 만들어 보세요.

돈 책에 같은 기능을 적용할 때:

> 책을 읽고 더 알고 싶은 돈 질문 하나와 그 답을 알아볼 순서를 말해 보세요.

힌트:

- 무엇이 궁금한가요?
- 먼저 어디에서 찾아볼까요?
- 누구에게 물어볼 수 있을까요?
- 찾은 정보가 믿을 만한지 어떻게 확인할까요?

이 문항은 `extension`으로 기록하며 객관 정답을 두지 않는다.

## 10. 말하기 기록과 평가

### 아이에게 보여 주는 결과

말하기는 맞음·틀림으로 표시하지 않는다.

```text
책 속 단서       4 / 5
말하기·녹음      4 / 4 완료
줄거리 낭독      저장 완료
```

별과 객관 정답률은 객관 문제 5개만으로 계산한다. 녹음 길이와 말하기 활동 수를
객관 점수에 더하지 않는다.

### 내부 관찰용 루브릭

보호자 피드백이나 향후 연구 목적으로 아래 루브릭을 사용할 수 있다. 초기 제품에서는
자동 채점하지 않고 기록 구조만 준비한다.

| 항목 | 0점 | 1점 | 2점 |
|---|---|---|---|
| 과제 충족 | 질문과 무관하거나 무응답 | 일부만 수행 | 요구한 내용을 모두 수행 |
| 책 속 정보 | 근거 없음 | 관련 정보 1개 | 관련 정보 2개 이상 |
| 조직 | 낱말만 나열 | 문장으로 표현 | 순서·비교 표현으로 연결 |

`extension` 문제는 책 속 정보 점수 대신 `질문과 조사 계획의 구체성`을 관찰한다.


`exampleForGuardian`은 아이가 녹음하기 전에 보여 주지 않는다.

## 12. 생성 결과 형식

책 한 권의 문제 생성 결과는 아래 순서로 출력한다.

1. 책 메타데이터
2. 장면 근거표
3. Lv1 객관 문제 6개
4. Lv2 시작 녹음 대본
5. Lv2 객관 문제 5개
6. Lv2 말하기·녹음 문제 4개
7. 객관 정답표와 보기 검수표
8. Lv1–Lv2 중복 검사표
9. 원문 검증이 필요한 주장 목록
10. 보호자 검수 체크리스트

생성기는 불확실한 내용을 임의로 메우지 말고 다음처럼 별도 보고한다.

```yaml
verificationIssues:
  - claim: 우유를 차갑게 옮기는 과학적 이유
    reason: 현재 장면은 차갑게 옮긴다는 사실만 제시함
    action: 원문 페이지 또는 별도 과학 자료 확인 필요
```

## 13. 최종 검수 체크리스트

### 출처

- [ ] 모든 객관 정답에 직접 근거가 있는가?
- [ ] 모든 근거 ID가 실제 장면표에 존재하는가?
- [ ] 책에 없는 원인·감정·결과를 만들어 내지 않았는가?
- [ ] 원문 미확인 내용을 `page-verified`로 표시하지 않았는가?

### 보기 자연스러움

- [ ] 네 보기가 모두 같은 의미 범주에 속하는가?
- [ ] 네 보기의 문법 형식, 시제, 조사, 종결 표현이 같은가?
- [ ] 정답만 유난히 길거나 자세하지 않은가?
- [ ] 책을 읽지 않고 보기 모양만으로 정답을 찾기 어려운가?
- [ ] 황당하거나 웃기기 위한 오답이 없는가?
- [ ] 부분적으로 맞는 두 번째 답이 없는가?
- [ ] 모든 선택형 문항에 `optionAudit`이 있는가?
- [ ] `awkwardnessFlags`가 남은 문항을 모두 다시 만들었는가?
- [ ] 보기 생성과 2차 검수가 분리되어 실행되었는가?
- [ ] `optionReviewStatus`가 `approved`가 아닌 문항이 공개 대상에서 제외되었는가?

### Lv1

- [ ] 말하기와 녹음 문제가 모두 제거되었는가?
- [ ] 아이가 누르기·선긋기·순서 놓기만으로 스스로 완료할 수 있는가?
- [ ] 모든 선택형 문항의 보기가 정확히 4개인가?
- [ ] 순서 카드가 정확히 4개인가?
- [ ] 첫 오답 뒤 한 번 더 기회를 제공하는가?
- [ ] 빈칸 완성과 책 전체의 중심 생각 문제가 제외되었는가?
- [ ] 문제 전용 이미지와 이미지 생성 프롬프트가 모두 제외되었는가?
- [ ] `image-choice`, `visual`, `imageOptions` 필드가 없는가?

### Lv2

- [ ] 문제 전에 줄거리 낭독 녹음이 있는가?
- [ ] 객관 5문제와 말하기·녹음 4문제가 있는가?
- [ ] 객관 문제와 말하기 문제가 섞여 있는가?
- [ ] 4장면 순서 문제가 있는가?
- [ ] 책 전체의 중심 생각을 묻는 문제가 있는가?
- [ ] 모든 말하기 문제가 실제 녹음을 요구하는가?
- [ ] 말하기 예시 답안을 녹음 전에 아이에게 공개하지 않는가?

### 레벨 중복

- [ ] Lv1과 Lv2의 질문 문장과 정답이 반복되지 않는가?
- [ ] 같은 근거를 사용했다면 요구하는 사고 활동이 분명히 다른가?
- [ ] Lv2가 Lv1 정답 하나만 기억해서 풀 수 있는 문제가 아닌가?
- [ ] 모든 Lv2 문항에 가장 가까운 Lv1 문항과의 중복 검사 결과가 있는가?
- [ ] `duplicateRisk: high` 문항이 모두 교체되었는가?

### 결과와 안전

- [ ] 객관 점수와 말하기 완료 수를 분리했는가?
- [ ] 녹음 길이를 정답이나 문해력 점수로 사용하지 않는가?
- [ ] 음성 삭제 기능과 저장 위치를 보호자에게 알리는가?
- [ ] 모든 주요 누르기 영역이 최소 44×44 CSS 픽셀인가?
- [ ] 일반 탭과 한 손가락 스크롤이 유지되는가?

## 14. 생성기용 핵심 지시문

아래 내용을 문제 생성 프롬프트의 고정 지시문으로 사용할 수 있다.

> 제공된 책의 장면 근거만 사용해 Lv1 객관 문제 6개와 Lv2 문제 9개를 만든다.
> Lv1에는 말하기·녹음·자기평가 문제를 만들지 않고 모든 선택형 문항에 보기 4개를
> 제공하며 순서 문제도 장면 카드 4개로 만든다. Lv1 퀴즈용 이미지, 이미지 선택지,
> 이미지 생성 프롬프트는 만들지 않는다. Lv2는 객관 문제 5개와
> 실제 녹음이 필요한 말하기 문제 4개를 권장 순서대로 섞는다. 모든 객관 정답은
> 장면에서 직접 확인할 수 있어야 하며, 근거 ID와 근거 요약을 기록한다. 책에 없는
> 사실은 만들지 말고 검증 필요 목록으로 분리한다. 말하기 문제는 맞음·틀림으로
> 자동 채점하지 않으며 객관 점수와 별도로 완료 여부만 기록한다. Lv1에서는 빈칸
> 완성과 책 전체의 중심 생각을 사용하지 않는다. Lv2를 만들 때 Lv1 전체 문항을
> 제외 목록으로 함께 검토하고, 가장 비슷한 Lv1 문항과 질문·정답·근거·사고 활동을
> 비교한 중복 검사표를 출력한다. 중복 위험이 높은 Lv2 문항은 출력 전에 다시 만든다.
> 모든 보기는 같은 범주와 문법 형식을 사용하고, 책에 나온 정보의 역할·장면·순서를
> 바꾸어 그럴듯한 오답을 만든다. 엉뚱한 단어와 억지 표현을 사용하지 않는다. 각 객관
> 문항에 보기 검수표를 출력하며 어색함 표시가 하나라도 남으면 보기를 다시 만든다.
